Trước khi dùng tính năng dịch

PolyTranslate gửi phần văn bản bạn chọn hoặc văn bản nhận từ OCR tới Google Translate. Nếu bạn chọn DeepL, văn bản và API key của bạn được gửi tới DeepL. Ảnh OCR được xử lý trên thiết bị. Cài đặt, API key, ghi chú học chữ Hán và ảnh bạn ghim được lưu trong Chrome trên thiết bị này.
