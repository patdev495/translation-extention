# Account-owned learning library

The companion website owns each learner's Learning Library so the extension can save Chinese text into that learner's folders and the learner can manage it on the web. The alternative of keeping this new library only in extension-local storage would avoid an account and server, but would not provide the requested personal web library across devices. A linked extension may hold saves temporarily while offline and sync them when connectivity returns; source page and PDF addresses are not part of a Saved Learning Item.
